# VR + Interfaz Cerebro-Computadora (BCI)

Práctica de Interacción Hombre-Máquina construida con A-Frame. Simula una diadema EEG que emite valores de atención y meditación, además de eventos de parpadeo.

## Funcionalidad

- Atención: modifica la altura y el tamaño de la esfera.
- Meditación: cambia el color de la esfera.
- Parpadeo: genera un pulso visual y desplaza al usuario hacia delante.
- Objeto adicional: toro violeta flotante y animado.
- Autor visible en el HUD y dentro de la escena 3D: Angel Valle.

## Ejecutar localmente

El proyecto es estático. Puede servirse con cualquier servidor HTTP, por ejemplo:

```bash
npx serve .
```

Luego abre la URL mostrada por el servidor en un navegador compatible con WebGL.
